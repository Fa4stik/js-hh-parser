# API для извлечения навыков из вакансий

API использует модель Qwen3-8B для анализа описаний вакансий и извлечения релевантных софт и хард навыков.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск API

```bash
# Из корня проекта
cd src/ai
python qwen.py
```

API будет доступно по адресу: `http://localhost:8000`

## Эндпоинты

### POST /api/vacancy

Извлекает навыки из описания вакансии.

**Запрос:**
```json
{
    "body": "Описание вакансии"
}
```

**Ответ:**
```json
{
    "soft": ["навык1", "навык2", ...],
    "hard": ["навык1", "навык2", ...]
}
```

### GET /health

Проверка состояния API и модели.

### GET /

Простая проверка работоспособности.

## Пример использования

```bash
curl -X POST "http://localhost:8000/api/vacancy" \
     -H "Content-Type: application/json" \
     -d '{"body": "Нужен разработчик Python с опытом работы с FastAPI, умением работать в команде и аналитическим мышлением"}'
```

## Примечания

- При первом запросе модель будет загружена (может занять время)
- Модель работает лучше на GPU, но также поддерживает CPU
- API автоматически загружает навыки из файлов `disco/skils/soft.txt` и `disco/skils/hard.txt`
