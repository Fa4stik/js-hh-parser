# Бот для обработки вакансий

Система для автоматической обработки вакансий с анализом навыков через API и управлением через Telegram бота.

## Компоненты системы

### 1. `vacancy_processor.py` - Модуль обработки вакансий

- Чтение Excel файлов с вакансиями
- Очистка HTML тегов из описаний
- Отправка запросов к API для анализа навыков
- Сохранение результатов в CSV файлы

### 2. `process_vacancies.py` - Скрипт обработки

- Обработка вакансий по батчам (по умолчанию 100 штук)
- Сохранение в файлы формата `[offset].csv`
- Поддержка продолжения обработки с любого места

### 3. `main.py` - Telegram бот

- **Автоматический запуск обработки** при старте бота
- `/get_process` - показать прогресс обработки
- `/start_processing` - запустить обработку вручную
- `/stop_processing` - остановить обработку
- `/merge_vacs` - объединить все CSV файлы
- `/merge_by_id` - объединить с исходным файлом

### 4. `setup.py` - Скрипт установки

- Автоматическая установка зависимостей
- Проверка настроек Telegram API
- Валидация окружения

## Установка

1. **Активируйте виртуальное окружение:**

   ```bash
   source env/bin/activate
   ```

2. **Запустите скрипт установки:**

   ```bash
   cd src/bot
   python setup.py
   ```

3. **Убедитесь, что в `meta.py` настроены корректные токены:**
   - `BOT_TOKEN` - токен Telegram бота
   - `API_URL` - URL для API анализа навыков
   - `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` - для расширенного функционала

## Использование

### Обработка вакансий

**Базовый запуск (обработка всех вакансий по 100 штук):**

```bash
python process_vacancies.py
```

**Обработка с параметрами:**

```bash
# Обработать только 5 батчей по 50 вакансий
python process_vacancies.py --batch-size 50 --max-batches 5

# Продолжить обработку с 1000-й строки
python process_vacancies.py --start-from 1000

# Указать конкретный файл
python process_vacancies.py --excel-file /path/to/file.xlsx
```

### Telegram бот

**Запуск бота:**

```bash
python main.py
```

**Команды бота:**

- `/start` - приветствие и список команд
- `/get_process` - статистика обработки (количество файлов × 100)
- `/get_by_offset` - получить конкретный CSV файл по offset (4 → 100.csv, 150 → 200.csv)
- `/start_processing` - запуск обработки вручную
- `/stop_processing` - остановка текущей обработки
- `/merge_vacs` - объединение всех CSV в `merged_results.csv` + отправка файла
- `/merge_by_id` - объединение только обработанных вакансий + отправка Excel файла
- `/fill_empty` - заполнение пустых навыков в merged_results.csv с прогрессом
- `/statistic` - статистика по файлу merged_with_original.xlsx (пропуски навыков)
- `/fill_hard_skills` - заполнение пустых hard_skills из merged_with_original.xlsx
- `/merge_hard_with_original` - объединение hard_skills с оригинальным файлом
- `/help` - справка по командам

🔄 **При запуске бота автоматически запускается фоновая обработка вакансий!**

## Формат данных

### Входной файл (`merged_vacs.xlsx`)

| Колонка     | Тип    | Описание                                 |
| ----------- | ------ | ---------------------------------------- |
| id          | number | Уникальный идентификатор вакансии        |
| description | string | Описание вакансии (может содержать HTML) |

### Выходные файлы (`[offset].csv`)

| Колонка     | Тип    | Описание                          |
| ----------- | ------ | --------------------------------- |
| id          | number | ID вакансии                       |
| hard_skills | string | Список хард скиллов через запятую |
| soft_skills | string | Список софт скиллов через запятую |

### API запрос/ответ

**Запрос (все навыки):**

```json
{
	"body": "описание вакансии без HTML тегов"
}
```

**Запрос (только hard skills):**

```json
{
	"body": "описание вакансии без HTML тегов",
	"skill": "hard"
}
```

**Запрос (только soft skills):**

```json
{
	"body": "описание вакансии без HTML тегов",
	"skill": "soft"
}
```

**Ответ:**

```json
{
	"soft": ["коммуникабельность", "работа в команде"],
	"hard": ["Python", "PostgreSQL", "Docker"]
}
```

**Параметр `skill` в body:**
- Не указан - поиск всех навыков
- `"skill": "hard"` - поиск только технических навыков
- `"skill": "soft"` - поиск только мягких навыков

## Требования

- Python 3.8+
- Виртуальное окружение (рекомендуется)
- Доступ к API для анализа навыков
- Telegram Bot Token

## Зависимости

Устанавливаются автоматически через `setup.py`:

- pandas
- requests
- beautifulsoup4
- python-telegram-bot
- openpyxl
- xlrd

## Ограничения

- Размер файлов для Telegram бота: до 2GB
- Пауза между API запросами: 0.1 секунды
- Таймаут API запросов: 30 секунд

## Устранение неполадок

**Ошибки импорта модулей:**

```bash
# Убедитесь, что виртуальное окружение активно
source env/bin/activate
python setup.py
```

**Ошибки Telegram API:**

- Проверьте корректность `BOT_TOKEN` в `meta.py`
- Убедитесь в доступности интернета
- Проверьте права бота в чате

**Ошибки обработки файлов:**

- Убедитесь, что `merged_vacs.xlsx` существует
- Проверьте наличие колонок `id` и `description`
- Убедитесь в доступности API по указанному URL
